# Concept previews

Unsolicited concept landing pages for local businesses on the Costa del Sol,
built so each owner can see what a website could look like before deciding.

Not affiliated with or endorsed by any business shown. Published only so each
proposal can be viewed at a link, and excluded from search engines via robots.txt.
Happy to remove any page on request.

Content is limited to each venue's own public Google listing and public reviews.
Opening hours are never published unless verified with the owner — see the
`hoursConfirmed` flag in `site.js`.
